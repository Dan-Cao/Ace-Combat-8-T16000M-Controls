# Ace Combat 8 — T.16000M Controls

A one-page reference card for flying Ace Combat 8 with a Thrustmaster T.16000M stick, using the game's built-in preset.

**[Open the card](https://dan-cao.github.io/Ace-Combat-8-T16000M-Controls/)**, or open `index.html` in any browser. Each control is labelled with what it does in game and the gamepad prompt it stands in for, so on-screen prompts like "press B" are easy to match to the stick.

The card uses a dark theme so it's easy on the eyes on a second monitor next to the game. Press **Full screen** to fill the display.
